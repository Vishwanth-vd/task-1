# Data Cleaning with Pandas – Marketing Campaign Dataset

## 📌 Description
This project focuses on data preprocessing tasks using **Python (Pandas)** in **Google Colab**. The dataset used is `marketing_campaign.csv`.

## 🧹 Tasks Performed
1. Identified and handled missing values using `.isnull()` and `.dropna()`.
2. Removed duplicate rows using `.drop_duplicates()`.
3. Standardized text columns like `Gender` and `Country`.
4. Converted date columns to `dd-mm-yyyy` format.
5. Cleaned and renamed column headers for uniformity.
6. Checked and fixed data types.
